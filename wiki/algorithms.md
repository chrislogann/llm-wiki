# Algorithms

**Summary**: An algorithm is a plan consisting of a sequence of step-by-step, logical instructions designed to solve a problem, carry out a task, process data, or automate a process.

**Sources**: `What is an algorithm - Algorithms - KS3 Computer Science Revision - BBC Bitesize.md`

**Last updated**: 2026-08-04

---

Algorithms represent the final blueprint before writing code. A computer program is simply an algorithm translated into a programming language (source: What is an algorithm - Algorithms - KS3 Computer Science Revision - BBC Bitesize.md).

## Core Concepts

- **Representation**: Algorithms must have a clear starting point, a finishing point, and unambiguous instructions. They are commonly planned using **pseudocode** (simplified plain English instructions) or **flowcharts** (visual flow diagrams) (source: What is an algorithm - Algorithms - KS3 Computer Science Revision - BBC Bitesize.md).
- **Garbage In, Garbage Out (GIGO)**: A computer can only follow instructions exactly as they are given. A poorly planned algorithm will result in a flawed or incorrect program (source: What is an algorithm - Algorithms - KS3 Computer Science Revision - BBC Bitesize.md).
- **Everyday Equivalents**: Humans use algorithms constantly for daily routines, such as following a recipe, tying shoelaces, getting dressed, or making a cup of tea (source: What is an algorithm - Algorithms - KS3 Computer Science Revision - BBC Bitesize.md).
