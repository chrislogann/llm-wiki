# LLM Wiki Query

1. Start with `Wiki/index.md`.
2. Search the catalog with `scripts/wiki_tool.py search-catalog`.
3. Open the most relevant compiled notes.
4. Read Raw sources only when evidence is missing.
5. Cite the compiled note and source note when needed.
