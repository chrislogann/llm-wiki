
# Naming Conventions

- Use sentence-case titles in note content.
- Keep file names readable and stable.
- Use `Wiki/Topics/` for broad organizing notes.
- Use `Wiki/Concepts/` for reusable ideas and definitions.
- Use `Wiki/Entities/` for people, places, systems, or objects.
- Use `Wiki/Projects/` for project-specific summaries.
- Use `Wiki/Logs/` for dated progress notes.
