
# Lint Checklist

- Compiled notes have exactly one allowed tag.
- Compiled notes have valid `sources` entries.
- `source_count` matches the number of sources.
- Raw notes include the required source frontmatter fields.
- `Processed: true` sources are backed by Wiki coverage.
- `Wiki/catalog.jsonl` is current.
- `Schema/source-manifest.jsonl` is current.
